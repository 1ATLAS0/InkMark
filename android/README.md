# InkMark for Android

Capacitor application of the InkMark project. The editor engine is shared with the desktop
application, so documents render identically on both.

Build instructions, release process and known issues live in the repository root:
[README](../README.md) · [ROADMAP](../ROADMAP.md).

This directory contains code from
[Renakoni/marktext-android](https://github.com/Renakoni/marktext-android) (MIT) and, through it,
from [marktext/marktext](https://github.com/marktext/marktext) (MIT) and
[@muyajs/core](https://github.com/marktext/muya) (MIT). Copyright notices are retained; see
`LICENSE` in this directory.

---

本目录是 InkMark 的 Android 端应用（Capacitor），与桌面端共用同一编辑引擎，同一文档在两端渲染结果一致。
