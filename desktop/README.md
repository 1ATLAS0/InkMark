# InkMark for desktop

Electron application of the InkMark project. Editing and rendering happen in a single view: block
markup is shown while the cursor is inside a block and collapses once the cursor leaves.

Build instructions, release process and known issues live in the repository root:
[README](../README.md) · [ROADMAP](../ROADMAP.md).

This directory contains code from [marktext/marktext](https://github.com/marktext/marktext) (MIT) and
[@muyajs/core](https://github.com/marktext/muya) (MIT). Copyright notices are retained; see
`LICENSE` in this directory.
